Web Application Programming and Hacking

Course Overview

As a student in EECE4005-001/8095-001: Web Application Programming and Hacking, I gained practical, end-to-end experience in building and securing modern web applications. The course combined full-stack development with real-world security training. On the development side, I learned how to build responsive and interactive web interfaces using HTML5, CSS, and JavaScript, and how to connect these front-end systems to dynamic back-end services using PHP and MySQL. I also worked with APIs, session management, and database-driven applications. I was exposed to common web vulnerabilities such as cross-site scripting (XSS), SQL injection, session hijacking, and cross-site request forgery (CSRF). More importantly, I learned how to both identify and mitigate these risks through secure coding techniques. The course was highly hands-on and industry-aligned. I developed and tested applications in a Linux-based environment using tools like VirtualBox and Ubuntu 22.04, and used GitHub for version control and collaborative workflows. Beyond technical skills, I also developed a better understanding of how secure web systems support business needs—protecting user data, maintaining system integrity, and ensuring reliable online services. The course emphasized building applications that are not only functional, but also resilient against real-world attacks, which is essential for any production-ready system in today’s digital economy.
