Web Application Programming and Hacking (WAPH)

This page introduces the course EECE4005-001/8095-001: Web Application Programming and Hacking and summarizes the hands-on projects completed throughout the semester.

Course Summary

In this course, I learned full-stack web development and web security fundamentals. The course covered client-side development using HTML, CSS, and JavaScript, and server-side development using PHP and MySQL. I also learned how to identify and mitigate common web vulnerabilities such as SQL injection, Cross-Site Scripting (XSS), session hijacking, and Cross-Site Request Forgery (CSRF).

A major focus of the course was secure programming practices and hands-on hacking exercises that demonstrated how real-world attacks occur and how to prevent them.
